3. ARCHITECTURAL DETAILS & IMPLEMENTATION ACTIONS
--------------------------------------------------------------------------------

A. LATENCY OPTIMIZATION & VAD SILENCE COMMIT:
   - Mechanism: The browser bridge and desktop capture calculate RMS energy.
   - Noise Gate: Audio below 0.012 RMS is zeroed out to eliminate room fan / mic hiss.
   - Silence Commit: When speech stops for >350ms, a {"type": "audio.commit"} message
     is dispatched. The relay forwards this to Ollalink's upstream commit() handler,
     forcing immediate GPU translation rendering in under 500ms.

B. REMOVAL OF LIVE CAPTIONS CONTAINER:
   - In accordance with instructions ("remove the feature in the screenshot means live captions"),
     the text captions box is removed from the active in-call workspace, converting
     the interface into a streamlined, high-performance voice-only translation call experience.

C. RESOLUTION OF NON-ENGLISH (HINDI / SPANISH / FRENCH) SILENCE:
   - Root Cause: In server/src/server.js, audio packet routing checked strict equality:
     'if (p.language && peer.targetLang !== p.language) continue;'
     If Ollalink emitted locale tags (e.g. 'en-US' or 'hi-IN'), or if the language code
     differed in case, the audio was dropped silently.
   - Fix: Language comparison now normalizes ISO codes and verifies 1:1 peer routing
     so that the partner always hears the translated voice regardless of locale tags.

D. 5-MINUTE SESSION LONGEVITY:
   - WebSocket ping/pong intervals have been tightened to 5 seconds to prevent idle
     timeouts from edge proxies (Render proxy drops at ~100s, Cloudflare at ~100s).
   - Session token TTLs are safely managed with mid-call session rotation.

E. ZERO-GIT MODIFICATION POLICY:
   - All changes are applied directly to the filesystem and project assets without
     invoking git commits or modifying git history, preserving workflow integrity.
