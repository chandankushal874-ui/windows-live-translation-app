1. EXECUTIVE SUMMARY & SYSTEM OVERVIEW
----------------------------------------------------------------------------------------
Ollalink Translate is an ultra-low-latency 1:1 real-time voice-to-voice translation system
built for Windows. It couples a native Tauri 2 desktop client (Rust + CPAL audio engine)
with a high-throughput Node.js relay server and Ollalink Sound-Stream GPU inference.

Key Specifications:
  * UI Footprint: Vanilla TypeScript/HTML/CSS (Vite bundle < 12 kB gzip, zero heavy frameworks)
  * Audio Capture: CPAL 16 kHz 16-bit mono PCM chunks (20 ms frame, 120 ms jitter buffer)
  * End-to-End Latency Target: < 400 ms cross-language conversational throughput
  * Security: HMAC SHA-256 session tokens with automatic 80% TTL renewals
  * Room Topology: Pure 1:1 peer isolation with 6-character collision-resistant codes
